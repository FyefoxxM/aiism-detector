# AIism Detector

A linting tool for writers who don't want their drafts to sound like they were generated by a language model that learned English from LinkedIn posts and corporate whitepapers.

**[Try it live](https://fyefoxxm.github.io/aiism-detector)**

---

## What it does

Paste your draft. Get called out.

The detector scans for 75+ patterns across four categories:

- **Vocabulary** — words statistically overrepresented in AI output: *tapestry, embark, pivotal, meticulous, holistic, nuanced, curated,* and about 50 more
- **Phrases** — throat-clearing constructions that add zero information: *"it's important to note," "at its core," "moving forward," "in today's fast-paced world"*
- **Transitions** — stacked formal connectors that signal nobody actually wrote this: *moreover, furthermore, additionally, consequently* (especially when they appear in consecutive sentences)
- **Cadence** — structural patterns like broetry (3+ consecutive dramatic one-liners) and the participial close (*"...revealing key insights"*)

If flags are found, it generates a roast. Four severity tiers. Pattern-specific callouts. Copyable for LinkedIn if you want to use it on someone else's post.

Everything runs in the browser. Nothing is sent anywhere.

## CLI usage

```bash
# Scan a file
python aiism_detector.py draft.txt

# Pipe from stdin
cat draft.txt | python aiism_detector.py
```

Output groups flags by line, labels each by category, and gives a pattern breakdown at the end.

---

## Why this exists

AI-generated content has tell-tale patterns. Some are vocabulary (certain words appear in AI output at 10-100x the rate they appear in human writing). Some are structural (the staccato one-liner cadence, the participial phrase close, the transition stack). Some are phrases that AI uses to sound thorough without saying anything specific.

This tool was built for writers who use AI as part of their workflow and want to catch the residue before it ships, and for editors who want a fast first pass on submitted drafts.

It is not a detector. It does not tell you whether something was written by AI. It tells you whether your writing shares patterns with AI output, which is a different and more useful question.
